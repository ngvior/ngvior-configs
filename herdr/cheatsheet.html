Panes

alt+hjkl Focus pane left / down / up / right
prefix+hjkl Focus pane, prefix fallback
alt+v Split right (vertical)
alt+d Split down (horizontal)
prefix+v/- Split right / down, prefix fallback
prefix+space Last pane — back and forth
prefix+tab Cycle to next pane
prefix+shift+tab Cycle to previous pane
prefix+z Zoom / unzoom focused pane
prefix+shift+hjkl Swap pane in that direction
prefix+shift+p Rename pane
prefix+e Edit scrollback in $EDITOR
prefix+x Close pane

ctrl+w is not bound here on purpose. It stays unix-word-rubout inside panes, which is worth more than a second way to close things.

Tabs

ctrl+t New tab
ctrl+1–9 Go to tab N
ctrl+tab Next tab
ctrl+shift+tab Previous tab
prefix+c New tab, prefix fallback
prefix+n/p Next / previous tab, prefix fallback
prefix+shift+t Rename tab
prefix+shift+x Close tab

Workspaces

ctrl+alt+l Next workspace
ctrl+alt+h Previous workspace
prefix+1–9 Go to workspace N — positional, not the workspace id
prefix+w Workspace picker
prefix+g Goto — opens navigate mode
prefix+b Toggle sidebar
prefix+shift+n New workspace
prefix+shift+w Rename workspace
prefix+shift+d Close workspace

No index ever uses shift. This keyboard is es,latam, where shifted digits produce different characters than US — shift+6 sends &, which Herdr reads as US shift+7. So the three scales use a plain digit: ctrl+N tab, prefix+N workspace, prefix+alt+N agent.

Agents

ctrl+alt+j Next agent — across all workspaces
ctrl+alt+k Previous agent
prefix+alt+1–9 Focus agent N in the sidebar
prefix+o Open notification target

Two axes, one mnemonic. alt+hjkl moves between panes inside a tab. ctrl+alt+hjkl moves between agents and workspaces — same directions, one modifier up, one scale up.

Worktrees

prefix+shift+g New git worktree as a workspace
prefix+shift+o Open an existing worktree
prefix+shift+k Remove worktree — asks to confirm

Session

prefix+/ This cheatsheet, as an overlay
prefix+? Built-in help overlay
prefix+s Settings
prefix+shift+r Reload config.toml
prefix+q Detach — agents keep running

Navigate prefix + g

↑↓ Move between workspaces
hjkl Move between panes
1–9 Jump by index
enter/esc Accept / cancel

Stays open. Unlike prefix mode, navigate mode does not close after one key — you keep moving without re-pressing the prefix.

Resize prefix + r

hjkl Grow / shrink the focused split
esc Exit resize mode

Ghostty outer layer

ctrl+shift+t New Ghostty tab — escape hatch if the Herdr server is down
ctrl+w Delete previous word — never claimed by Herdr
ctrl+shift+c/v Copy / paste
ctrl+shift+f Search Ghostty scrollback
ctrl+, Open Ghostty config
ctrl+shift+, Reload Ghostty config
super+space Input source switch (ibus) — why the prefix is not here

Ghostty is a dumb window. Its tabs and splits are unbound so Herdr owns all layout. Ghostty tabs are not persistent, carry no agent state, and do not survive a detach.
